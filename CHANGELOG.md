# Changelog

All notable changes to Migration Guard are documented in this file.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-09-13

### Added

- Central and tenant pending-migration analysis with CI and JSON reports.
- Data-aware safety rules, migration operation capture, and configurable policy thresholds.
- Explicit approval and expiring ignore exceptions.
- Release-readiness documentation and a PHP/Laravel compatibility test matrix.
